# 울타리 치기 (슬리더링크)

데블스 플랜3에 나온 '울타리 치기', 일본 니코리의 펜슬 퍼즐 **슬리더링크(Slitherlink)** 를 브라우저에서 혼자 푸는 웹 게임입니다.

플레이: https://jkh76.github.io/slitherlink/

## 규칙

- 점과 점 사이(가로·세로)에 선을 긋습니다.
- 칸 안의 숫자는 그 칸의 네 변 중 선이 그어진 개수입니다. 숫자가 없는 칸은 몇 개든 상관없습니다.
- 선 전체가 갈라지거나 교차하지 않는 **하나의 닫힌 고리**가 되면 클리어입니다.

## 기능

- **게임 시작**: 문제마다 가운데 '게임 시작' 버튼을 누르면 숫자가 나타나고 시간이 흐릅니다.
- **난이도**: 하 5×5 / 중 7×7 / 상 10×10. 문제는 매번 랜덤으로 만들어지고, 답은 항상 하나입니다.
- **펜**: 변을 탭하면 선, 다시 탭하면 지워집니다. 누른 채 끌면 여러 변을 한 번에 그립니다.
- **X 표시**: 선이 아닌 자리를 표시합니다. PC에서는 오른쪽 클릭으로도 됩니다.
- **지우개**: 확인 창에서 '예'를 누르면 전체 선과 X를 지웁니다.
- **되돌리기**: 마지막 동작을 취소합니다(전체 지우기 포함).
- **힌트보기**: 스테이지마다 3번. 확정되는 선 하나를 그어 주거나 잘못 그은 선을 알려 주고, 쓸 때마다 기록 시간에 30초가 더해집니다.
- **답안보기**: 확인 후 정답 고리(파란색)와 내가 이은 선(노란색)을 겹쳐 보여 줍니다. 그 문제는 기록에 남지 않고, 도구 자리에 '다음 문제' 버튼이 나옵니다.
- **클리어**: '성공!' 글자, 효과음, 색종이와 함께 최종 시간(풀이 시간 + 힌트 벌점)과 난이도별 최고 기록을 보여 줍니다.
- **잠시 멈춤**: 타이머 옆 ‖ 버튼. 판을 가리고 시간을 멈추며, ▶ 버튼으로 이어서 합니다. 다른 앱·탭으로 가면 자동으로 멈춥니다.
- **새 문제 연출**: 숫자가 화면 앞쪽에서 판 위로 떨어지며 나타납니다.
- **기록**: 난이도별 클리어 횟수와 가장 짧은 클리어 시간(힌트 벌점 포함)을 보여 줍니다. 브라우저에 저장됩니다.
- **가로 모드**: 태블릿을 가로로 들면 도구가 판 오른쪽에 세로로 놓이고, 판이 화면 높이에 맞춰 커집니다.
- **설정**: 효과음, 숫자 색 힌트, 자동 X 표시, 다크 모드.

## 실행

`index.html` 파일 하나로 동작합니다. 아이콘 파일(`favicon.ico`, `favicon-32.png`, `icon-192.png`, `apple-touch-icon.png`)은 같은 폴더에 둡니다. 서버, 빌드, 외부 라이브러리가 필요 없습니다.
